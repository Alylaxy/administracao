# Resumo das aulas

Este repositório é apenas um local para compartilhar com meus colegas de turma minhas anotações durante a aula.

# Como utilizar

1. Acessar o [link](https://github.com/Alylaxy/administracao/) do repositório;
2. Clicar na pasta Aulas presente no centro do website
3. Clicar no nome da aula que quer ver.
   
> A princípio não há nada além de arquivos em markdown, mas quando eu conseguir por minhas mãos nos slides das aulas, vou criar uma pasta adicional dentro da Aulas para cada dia diferente, com minhas anotações seguidas do pdf da aula.
